================================================================
 카카오톡 CS봇 - 핸드폰 연동 설정 가이드
================================================================

[1단계] 앱 설치
--------------
안드로이드 폰에서 아래 앱을 설치하세요:

  앱 이름: 채팅 자동응답 봇
  다운로드: https://play.google.com/store/apps/details?id=com.darktornado.chatbot

  * iOS는 지원하지 않습니다 (안드로이드 전용)


[2단계] 봇 스크립트 등록
-----------------------
1. 앱을 실행합니다
2. 우측 하단 "+" 버튼을 눌러 새 봇을 생성합니다
3. 봇 이름: "CS봇" (원하는 이름 가능)
4. API 유형: "API2" 선택 (중요!)
5. 아래 내용을 스크립트에 붙여넣기 합니다:

   → bot-script/kakao-bot.js 파일의 전체 내용을 복사하세요
   → 또는 GitHub에서 직접 복사:
     https://github.com/yeon-yi/kakao-cs-bot/blob/main/bot-script/kakao-bot.js


[3단계] 설정 변경 (필수)
-----------------------
스크립트 상단의 설정값을 확인합니다:

  var API_URL = "http://1.234.83.118:3000";
  var API_KEY = "csbot-webhook-2026!secret";

  → 이 값들은 이미 설정되어 있으므로 변경하지 마세요.

관리자 설정 (선택):
  var ADMIN_NAMES = ["관리자"];
  → 본인의 카카오톡 프로필 이름으로 변경하면
    관리자 명령어를 사용할 수 있습니다.

응답할 방 설정 (선택):
  var ALLOWED_ROOMS = [];
  → 빈 배열이면 모든 방에 응답합니다.
  → 특정 방만 응답하려면: ["방이름1", "방이름2"]


[4단계] 권한 허용
-----------------
1. 앱 상단 메뉴 → "알림 읽기 권한" 클릭
2. "채팅 자동응답 봇" 앱의 알림 접근 권한을 허용합니다
3. 카카오톡 알림이 정상적으로 읽히는지 확인합니다


[5단계] 봇 활성화
-----------------
1. 메인 화면에서 "CS봇" 우측 스위치를 켭니다
2. 하단 "전체 봇 활성화" 스위치도 켭니다
3. "컴파일" 버튼을 눌러 스크립트 오류가 없는지 확인합니다


[6단계] 테스트
--------------
1. 카카오톡에서 아무 채팅방에 메시지를 보냅니다
2. 운영시간(09:50~18:30, 평일) 내에만 응답합니다
3. 봇 앱의 "로그" 탭에서 동작 확인 가능합니다

테스트 시간이 운영시간 밖이라면:
  → 관리자 명령어로 상태 확인: "!봇상태" 입력
  → 서버 로그에서 확인 가능


================================================================
 관리자 명령어 (카카오톡에서 직접 입력)
================================================================

  !봇상태     - 봇 상태, 서버 연결, 운영시간 확인
  !봇켜기     - 봇 활성화
  !봇끄기     - 봇 비활성화 (응답 중지)
  !에러초기화  - 연속 에러 카운트 리셋

  * ADMIN_NAMES에 등록된 이름으로만 사용 가능

================================================================
 도메인 연결 (선택, 권장)
================================================================

  현재는 IP(1.234.83.118)로 접속 중이며 자체서명 SSL입니다.
  도메인을 연결하면 정식 SSL(Let's Encrypt)을 적용할 수 있습니다.

  1. 도메인 구매 (예: csbot.example.com)
  2. DNS A 레코드를 1.234.83.118로 지정
  3. 서버에서 certbot 실행:
     sudo certbot --nginx -d csbot.example.com
  4. Nginx 설정의 server_name을 도메인으로 변경
  5. 완료 후 HTTPS가 정상 작동합니다
